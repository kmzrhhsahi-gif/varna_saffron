راهنمای سایت وارنا زعفران
==========================

اجرا روی کامپیوتر
- پوشه را در VS Code باز کنید و افزونهٔ Live Server را نصب کنید.
- روی index.html راست‌کلیک کنید و Open with Live Server را بزنید.
  (فایل را با دابل‌کلیک هم می‌توانید باز کنید، ولی Live Server بهتر است.)

چه چیزی را کجا عوض کنم؟
- قیمت و محصولات:      data/products.js   (قیمت به هزار تومان؛ null یعنی استعلام قیمت)
- تاریخ قیمت:          data/products.js   (PRICES_DATE)
- لینک‌ها و شماره:     data/site.js       (واتساپ و شماره تلفن را اینجا بنویسید)
- متن داستان و سؤالات: index.html
- رنگ‌ها:              css/base.css بالای فایل (بخش :root)

فونت فارسی (مهم برای سرعت در ایران)
- فایل Vazirmatn.woff2 را از github.com/rastikerdar/vazirmatn دانلود کنید
  و داخل assets/fonts/ بگذارید. سایت اول از همین فایل استفاده می‌کند
  و به اینترنت خارجی (CDN) نیازی نمی‌ماند.

انتشار روی اینترنت (یکی را انتخاب کنید)
1) هاست ایرانی (پیشنهاد برای مشتری ایرانی، سریع‌تر است):
   دامنهٔ .ir و یک هاست ساده بخرید، وارد cPanel یا DirectAdmin شوید و همهٔ فایل‌های
   پوشه را (نه خود پوشه را) داخل public_html آپلود کنید.
2) رایگان: Netlify (netlify.com، بخش Drop) یا GitHub Pages. در ایران ممکن است
   بعضی وقت‌ها کند یا فیلتر باشد، پس برای مشتری ایرانی تست کنید.

بعد از گرفتن دامنه
- در index.html آدرس og:image را به آدرس کامل تبدیل کنید.
- فایل sitemap.xml بسازید و خط Sitemap را در robots.txt فعال کنید.
- سایت را در Google Search Console ثبت کنید.

نکته‌ها
- عکس‌ها از قبل به webp تبدیل و کوچک شده‌اند. عکس جدید را هم با همین فرمت بگذارید
  (دو نسخه: name.webp برای بزرگ و name-sm.webp برای کارت).
- اگر محصول جدید اضافه می‌کنید، فقط یک آبجکت جدید به data/products.js اضافه کنید.
